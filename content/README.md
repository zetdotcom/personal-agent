# Content

Canonical local Second Brain data lives here. Raw evidence is preserved separately from organized PARA knowledge.

## Use

- Start every new input in `captures`.
- Store retrieved external material in `sources`.
- Store processed knowledge in `projects`, `areas`, `resources`, or `archives`.
- Store unassigned actions in `inbox` and review records in `reviews`.
- Read `docs/content-workflow.md` before processing or reorganizing content.

Do not create alternate content roots or silently bypass provenance links.
