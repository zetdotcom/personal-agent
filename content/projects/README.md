# Projects

Committed, finite outcomes currently being pursued. Project ends when outcome is completed, abandoned, or paused.

## Use

- Create project only after user commits to concrete outcome with next action.
- Give each project its own folder containing overview and supporting notes.
- Keep project actions, decisions, open questions, and relevant working material together.
- Move completed, paused, or abandoned project to `archives/projects`.

Uncommitted ideas belong in `resources/ideas`, not here.
