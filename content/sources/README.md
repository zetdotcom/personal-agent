# Sources

Retrieved external evidence such as YouTube transcripts, article extracts, or pasted source material. This folder separates source content from user request and agent summary.

## Use

- Store source material under `YYYY/MM` with URL and retrieval provenance.
- Preserve retrieved text; do not rewrite it as a summary.
- State clearly when transcript or complete source was unavailable.
- Link source record to originating capture and derived summary notes.

Use only when external material is actually available. Never invent a transcript or source record.
