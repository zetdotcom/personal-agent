# Captures

Immutable record of exactly what user submitted by text or voice. Captures preserve intent and provenance before any organization or summarization.

## Use

- Create one file under `YYYY/MM` before interpreting new input.
- Keep text below `# Raw transcript` unchanged unless user explicitly requests correction.
- Update only front matter during processing.
- Record every created or updated organized note in `generated_notes`.
- Use `needs-review` when ambiguity prevents safe processing.

Captures are evidence, not polished notes and not a PARA category.
