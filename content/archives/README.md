# Archives

Inactive material preserved for history, search, and possible reuse.

## Use

- Move completed, paused, abandoned, or no-longer-relevant PARA material here.
- Preserve whether item came from Projects, Areas, or Resources in subfolder structure.
- Treat archived content as historical context, not default current truth.
- Restore item to active PARA category if it becomes actionable again.

Archive instead of deleting organized knowledge.
